# هفته صفر: ویژگی `defer` در جاوااسکریپت

## ۱. مسئله

مرورگر فایل HTML را از بالا به پایین می‌خواند. صفحه از دو بخش ساخته می‌شود:

<ul dir="rtl" style="text-align: right; list-style-position: inside; padding-right: 0;">
<li><strong>HTML:</strong> اسکلت صفحه (دکمه، عنوان، فرم)</li>
<li><strong>JavaScript:</strong> رفتار صفحه (کلیک، نمایش پیام)</li>
</ul>

اگر تگ `script` داخل `head` باشد:

```html
<head>
    <script src="script.js"></script>
</head>
```

مرورگر همان‌جا دانلود و اجرای فایل را انجام می‌دهد و تا پایان کار، خواندن HTML را متوقف می‌کند.

دو مشکل پیش می‌آید:

1. فایل حجیم، نمایش صفحه را دیر می‌کند.
2. اگر اسکریپت به عنصری نیاز داشته باشد که هنوز ساخته نشده، آن را پیدا نمی‌کند و خطا می‌دهد.

## ۲. راه‌حل: `defer`

```html
<head>
    <script src="script.js" defer></script>
</head>
```

رفتار مرورگر با `defer`:

1. فایل JavaScript را **هم‌زمان** با خواندن HTML دانلود می‌کند.
2. برای دانلود، خواندن HTML را متوقف **نمی‌کند**.
3. اجرای اسکریپت را به **بعد از کامل شدن HTML** می‌اندازد.
4. چند اسکریپت `defer` را **به ترتیب نوشته‌شدن** اجرا می‌کند.

> **نکته:** اسکریپت‌های `defer` قبل از رویداد `DOMContentLoaded` اجرا می‌شوند.

## ۳. مثال

**index.html**

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <title>آموزش defer</title>
    <script src="script.js" defer></script>
</head>
<body>

    <button id="myButton">کلیک کن</button>

</body>
</html>
```

**script.js**

```javascript
const button = document.getElementById("myButton");

button.addEventListener("click", function () {
    alert("سلام!");
});
```

مراحل اجرا:

1. مرورگر فایل `script.js` را دانلود می‌کند، ولی اجرایش را نگه می‌دارد.
2. HTML تا آخر خوانده می‌شود و دکمه ساخته می‌شود.
3. اسکریپت اجرا می‌شود، دکمه را پیدا می‌کند و رویداد کلیک را به آن وصل می‌کند.
4. با کلیک روی دکمه، پیام `سلام!` نمایش داده می‌شود.

**بدون `defer`** (اسکریپت داخل `head`): کد قبل از ساخته شدن دکمه اجرا می‌شود، مقدار `button` برابر `null` است و `addEventListener` خطا می‌دهد.

## ۴. `defer` یا اسکریپت در انتهای `body`؟
</div>
روش دوم این است که اسکریپت درست قبل از `</body>` قرار بگیرد:

```html
<body>

    <button id="myButton">کلیک کن</button>

    <script src="script.js"></script>
</body>
```

این روش هم کار می‌کند، چون دکمه قبل از اسکریپت ساخته شده است.

| ویژگی | `defer` در `head` | اسکریپت در انتهای `body` |
|---|---|---|
| شروع دانلود | هم‌زمان با خواندن HTML | وقتی مرورگر به تگ اسکریپت برسد |
| توقف HTML هنگام دانلود | خیر | بله |
| زمان اجرا | بعد از کامل شدن HTML | هنگام رسیدن به تگ اسکریپت |
| دسترسی به عناصر | همه عناصر صفحه | عناصری که بالاتر از اسکریپت‌اند |
| ترتیب اجرای چند اسکریپت | حفظ می‌شود | به ترتیب نوشتن در صفحه |

**تفاوت سرعت:** با `defer` دانلود از ابتدا شروع می‌شود و با خواندن HTML هم‌زمان است. در روش انتهای `body`، دانلود دیرتر شروع می‌شود. اندازه این تفاوت به حجم فایل و سرعت شبکه بستگی دارد.

## ۵. نکات مهم
<ul dir="rtl" style="text-align: right; list-style-position: inside; padding-right: 0;">
    <li> defer فقط روی اسکریپت‌های خارجی (با src) اثر دارد و روی اسکریپت‌های درون‌خطی بی‌اثر است.</li>
    <li> اگر اسکریپت به عناصر صفحه نیاز دارد، defer در head انتخاب مناسبی است.</li>
    <li> اسکریپت در انتهای body هم روش معتبری است، ولی دانلودش دیرتر شروع می‌شود.</li>
    <li> اگر ترتیب اجرای چند فایل مهم است، defer ترتیب را حفظ می‌کند. async این تضمین را نمی‌دهد.</li>
</ul>
